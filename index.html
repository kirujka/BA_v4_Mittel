Готовые письма, собранные из блоков. Прочёл записку → нашёл похожую форму → меняешь только выделенное по записке.

Письмо собирается из готовых предложений. Сочинять на экзамене ничего не надо.

Блок — выученное предложение. В некоторых есть дырка. В каждой дырке есть ДЖОКЕР — вариант, который подходит к любой ситуации. А если шеф в записке сам диктует, что написать, — его слова вставляются в дырку.

Три правила

1
Не знаешь, что вставить — джокер. Менее точно, зато без ошибок.
2
Шеф продиктовал — бери его слова. По одному из трёх превращений (вкладка «Правила»).
3
Порядок блоков всегда один — это цепочка. Каждый блок цепляется за предыдущий. Номер блока — это его имя, а не место: место в письме написано на каждой карточке.
