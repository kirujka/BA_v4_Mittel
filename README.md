# Beschwerdeantwort — конструктор v4.4

Ответ на жалобу · Deutsch-Test für den Beruf B2, часть «Lesen und Schreiben». К каждой немецкой единице — русский перевод.

16 блоков: ядро 9 + второй круг 7. Письмо — **цепочка**: получили → извиняемся → почему → что делаем и когда → чтобы не повторилось → компенсация → (что нужно от клиента) → надежда и финал.

## Что изменилось в v4.4

| Блок | v4.3 | v4.4 |
|---|---|---|
| 4 | `Wie eine eingehende Prüfung ergeben hat, …` | твой исходник: `Aufgrund [причина] kam es zu dieser misslichen Situation.` + 3 причины «третье лицо» |
| 5 | `So sehr wir … weisen wir Sie darauf hin, dass …` (отказ) | твой исходник: `Wir möchten Sie jedoch darauf hinweisen, dass …` — «обращаем внимание», отказ только один из вариантов |
| 6 | `Die betreffenden Artikel …` | из твоего шаблона: `Die fehlenden Artikel werden … nachgeliefert.` / `Ein Ersatz wird Ihnen … zugesandt.` |
| 7 | один каркас с `bieten … an` | 7а деньги — твой исходник `Als Entschuldigung gewähren wir Ihnen …`; 7б вещь/услуга — `Als Zeichen unseres Entgegenkommens bieten wir Ihnen … an.` |
| 8 | `Zur Vermeidung ähnlicher Vorkommnisse` | твой исходник `Zur Vermeidung solcher Vorfälle` + 2 другие рамки + аварийный джокер |
| 14 | только «Termin» | `Sollte Ihnen [X] nicht zusagen, …` — дата, новая дата доставки, замена, любое предложение |
| порядок | 7 → 8 → 15 | 8 → 7 → 15: сначала «не повторится», потом компенсация, как в твоём шаблоне |

Новые формы письма: **Д** — срок позже требуемого, **Е** — виноваты не мы. Для каждой формы — готовый образец письма.
Проверка повторов слов отключена: повтор служебного слова баллов не снимает.
