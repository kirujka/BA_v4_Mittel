# Beschwerdeantwort — конструктор v3

Ответ на жалобу клиента · Deutsch-Test für den Beruf B2, часть «Lesen und Schreiben».
База: 56 заданий — 53 тренировочных из открытых источников + 3 реальных экзаменационных.

**13 каркасов + 2 фиксированные добавки + 3 необязательные · 7 причин · 81 слот · покрытие 56 из 56.**

К каждой немецкой единице — слову, конструкции, предложению, блоку — дан русский перевод. Везде, без исключений.

## Рабочие файлы

| Файл | Что это |
|---|---|
| `index.html` | Картотека, три дрилла, шпаргалка, правила и критерии. Открывается двойным кликом, интернет не нужен |
| `beschwerde_data.js` | Данные: блоки, причины, 60 формулировок шефа. Должен лежать в той же папке |


## Шесть вкладок приложения

1. **Картотека** — все 18 блоков с каркасами, слотами, ловушками и тренируемыми конструкциями C1. Фильтры: ядро / фиксированные добавки / необязательные, и по номеру блока.
2. **Дрилл: шеф → блок** — 60 настоящих формулировок из записок Teamleitung с переводом, ты выбираешь нужный блок из четырёх вариантов. **Главный тренажёр**: именно этот навык решает первый критерий оценки.
3. **Дрилл: рус → нем** — русская фраза, вспоминаешь немецкую, открываешь и сверяешь. Идёт по всем каркасам, слотам и причинам.
4. **Дрилл: причины** — семь причин, отдельно Genitiv и Akkusativ, с подсветкой окончания.
5. **Шпаргалка** — порядок сборки и все каркасы подряд, с переводом.
6. **Правила и критерии** — четыре официальных критерия telc и два правила сборки, которые вскрыл стресс-тест.

## Что учить наизусть

- **13 каркасов** — дословно, целиком, вместе с порядком слов
- **7 причин в Genitiv** — не забывать `-s` / `-es` в мужском и среднем роде
- **81 слот** — достаточно узнавать в списке, наизусть держать не обязательно
- **Порядок:** B1 → B2 → B3 → B4 → D1 → B7 → B8 → B13 → B5 → D2 → B6 → B9 → B10 → B11 → B12
