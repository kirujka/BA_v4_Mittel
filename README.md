# Beschwerdeantwort — конструктор v4.2 «минимум»

Ответ на жалобу клиента · Deutsch-Test für den Beruf B2, часть «Lesen und Schreiben».
К каждой немецкой единице — русский перевод. Везде, без исключений.

**16 блоков: ядро 9 + второй круг 7. В каждой дырке — джокер. Проверено на 56 заданиях: закрыты все 56.**

## Три правила

1. **Не знаешь, что вставить — джокер.** В каждой дырке есть вариант с пометкой ДЖОКЕР: подходит к любой ситуации, менее точно, но без риска.
2. **Шеф продиктовал — бери его слова.** Что предложить, в чём отказать, какой срок — переносишь из записки в дырку по одному из трёх превращений (А, Б, В). Выученный вариант тогда не нужен.
3. **Порядок блоков всегда один** — из шпаргалки, не из записки.

## Что нового в v4.2

| Что | Зачем |
|---|---|
| **Джокер в каждой дырке** | Страховка: пустой дырки или фразы, сочинённой на ходу, на экзамене не будет |
| **Три превращения слов шефа** (А — что предложить, Б — в чём отказать, В — срок) | Система стала открытой: не нужно заранее угадывать каждую ситуацию, слова даёт сама записка |
| **Четыре формы письма** (А виноваты · Б отказ · В дальше платно · Г разбираемся) | Не собираешь письмо из 16 блоков с нуля, а берёшь готовую форму и правишь её |
| **Одно правило Genitiv на все причины** | Все шесть причин мужского/среднего рода: aufgrund + eines + …en + …(e)s. Женских исключений нет |
| **Причины 3 → 6, из них три — твои** из исходного шаблона (`krankheitsbedingten Personalausfalls`, `Produktionsfehlers`, `internen Systemfehlers`) + джокер `eines bedauerlichen Zusammentreffens mehrerer ungünstiger Umstände` | Закрыты «поставщик» и «брак»; нового для заучивания — три фразы |
| **Срок встроен в блок 6** (вставка [когда]); «проблема уже устранена» — тоже вариант блока 6 | Минус два отдельных блока: 18 → 16 |
| **Блок 5: вставка «вина не наша»** — `die Ursache außerhalb unseres Verantwortungsbereichs liegt` | Задания 3 и 6 |
| **Блок 7: обратно `anbieten`**, две компенсации — через `sowie` | `gewähren` не работает с товарами; `sowie` убирает второй каркас |
| **Блок 9: вернулся зачин `Angesichts unserer langjährigen und vertrauensvollen Zusammenarbeit …`** | 10 заданий из 56 |
| **Правило: блоки 4 и 13 вместе не ставятся** | «Проверка показала» и «ещё проверяем» противоречат друг другу |

Твои неизменные части — блоки 1, 2, 3 и 9 — не тронуты (к блоку 9 добавлен только необязательный зачин).
